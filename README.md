# run-today-growth-ops-v2

`run-today-growth-ops-v2` 是一个用于生成中文《超脑俱乐部日报》的 Codex Skill。它面向信息过载、成长焦虑、想提升判断力与表达力的用户，把每日新闻、GitHub 应用、哲学观点、经济学视角、口才训练和深度哲思整合成一份可直接阅读的日报。

## 适合谁

- 社群运营者：每天需要稳定产出有判断力、有讨论价值的内容。
- 内容创作者：希望把新闻和知识转化成可讲、可写、可传播的观点。
- 学习型社群：需要用轻量日报带动成员思考、表达和讨论。
- 个人成长用户：希望从碎片信息里提炼长期记忆点。

## 输出内容

每次运行会生成一份《超脑俱乐部日报》，包含：

1. 五件值得理解的事：严格保持 1 条全球形势 + 4 条国内生活。
2. 今日 GitHub 热门应用：推荐一个真实、可访问、未重复使用的应用型仓库。
3. 今日哲学观点：用一个生活化故事连接哲学观点与经济学概念。
4. 每日口才训练：约 300 字中文朗读稿，附停顿、重音、气息和节奏提示。
5. 每日深度哲思：介绍一个历史上的哲学思想，并提出开放式思考问题。
6. 固定署名：大鱼-超级策划合伙人，联系微信：renzhiribao666。

## 核心规则

- 不虚构事实，不编造新闻、仓库、star 数、许可证或来源。
- 需要使用当前资料时必须 live search 或基于用户提供的材料。
- 正文不显示新闻来源链接、核验状态、核验时间、`待核验`、GitHub 元数据核验说明。
- 核验、去重和信息不足只保留在内部记录或 automation/Triage 摘要中。
- 不能重复历史日报中已经使用过的新闻主题、GitHub 仓库、哲学观点、经济学搭配、口才主题、深度哲思主题和核心记忆点。
- 不生成记忆卡拆解，不生成 PNG 图片，只输出正常日报正文。

## 安装方式

把整个 `run-today-growth-ops-v2` 目录复制到 Codex skills 目录，例如：

```bash
cp -R run-today-growth-ops-v2 ~/.codex/skills/
```

目录结构应保持如下：

```text
run-today-growth-ops-v2/
  SKILL.md
  README.md
  agents/
    openai.yaml
  references/
    output-template.md
    memory-card-template.md
```

## 使用方式

在 Codex 中输入：

```text
使用 run-today-growth-ops-v2 生成今天的超脑俱乐部日报
```

如果用于自动化任务，可以要求输出到固定路径，例如：

```text
每天在当前项目运行 run-today-growth-ops-v2，生成 reports/daily-growth-report-YYYY-MM-DD.md
```

## 输出边界

这个 skill 会尽量选择可核验、可去重、适合普通读者理解的内容。如果当天材料不足，不会强行编造；信息不足会写入自动化摘要，而不是写进日报正文。
